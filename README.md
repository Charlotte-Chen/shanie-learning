# Shanie學習

給自己家用的每日學習小幫手：每天打開就看到「今天的學習計劃」——寰宇 DWE 官方步驟、家長常見補充（另外標示）、今天要拿的廖彩杏書，以及可以跟孩子說的簡單英文句子。

網站：https://charlotte-chen.github.io/shanie-learning/

## 怎麼用
1. 打開「設定」：填廖彩杏書單的開始日（或直接選「今天是第幾週」），再選寰宇目前的顏色、第幾集、這個顏色從哪天開始。
2. 之後每天打開首頁就好。日期以台北時間計算。
3. 打勾、播放次數、「我有這本」都只存在這台裝置的瀏覽器（localStorage），沒有登入、沒有追蹤。

## 今天的計劃怎麼算
- **廖彩杏**：依《用有聲書輕鬆聽出英語力：一年52週100本英文繪本閱讀計畫》（親子天下，2012，ISBN 9789862415238）的 52 週、100 本週次表。每 7 天換下一週，這週的那組書每天播放 3 次；首頁每天輪一本當「共讀主角」。複習週會輪流列出要複習的那幾週。52 週後自動進入第 2 輪。
- **寰宇 DWE**：只列官網與官方使用說明公開寫到的內容（四色 Blue／Green／Lime／Yellow、同顏色教材一起用、各教材的用法）。官方逐週進度表在會員系統拿不到，所以本站不編週次課表；「家長常見補充」和「本站輪替建議」都另外標示為非官方。
- **今天可以說的話**：本站自己寫的簡單句子，依今天那本書的主題（動物、顏色、數數…）和寰宇教材挑選，不是書裡的原文。

## 資料與版權
- 書單資料：`data/lists/liao.json`（書名、作者、週次、ISBN、Open Library 連結與來源）。
- 封面：直接從 Open Library Covers API 載入，repo 裡沒有存任何封面圖、電子書或音檔。找不到封面的書會顯示文字卡。
- 寰宇資料：`data/programs/dwe.json`；對話句子：`data/talk.json`。

## 之後加別的書單
1. 照 `data/lists/liao.json` 的格式新增一個檔案，例如 `data/lists/xxx.json`（`books` + `weeks`）。
2. 在 `data/lists/index.json` 的 `bookLists` 加一行 `{"id": "xxx", "file": "data/lists/xxx.json", "name": "書單名稱"}`。
書單頁上方就會多一個切換按鈕。

純靜態 HTML／CSS／JS，不需要 build。
